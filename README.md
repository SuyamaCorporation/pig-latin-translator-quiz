# Pig Latin Translator & Text Quiz

A dual-mode app for translating text between English and Pig Latin, plus an interactive timed quiz. The translator applies standard Pig Latin rules: words starting with a vowel get "way" appended, while words starting with consonants have their leading consonant cluster moved to the end followed by "ay". The quiz shows a Pig Latin sentence and asks the player to type the English original within a 15-second countdown.

## Features

- Real-time English → Pig Latin translation as you type
- Reverse Pig Latin → English translation
- Quiz mode with 10 shuffled sentence prompts from a built-in sentence bank
- 15-second per-question countdown timer
- Score tracking across a full quiz round
- Skip button for passing on tough questions
- Restart button to reshuffle and replay
- Accessible tabs with ARIA roles and live regions for dynamic feedback
- No external API calls; fully self-contained
